    03

    Case files

    Four problems on Google Cloud, with the constraints and the decision for each. Clients are not named.

    01

    Upgrading Kubernetes 1.24 to 1.30

    Context
    Clusters still on Kubernetes v1.24, on-prem and in the cloud, already out of upstream support.
    Constraint
    Production traffic could not stop. Every step had to be planned and rehearsed first.
    Decision
    One minor version at a time, control plane first, then nodes rolled one at a time so pods always have somewhere to go.
    Result
    The clusters run v1.30 with no service disruption.

    02

    Shared storage on GKE without NFS

    Context
    SaaS workloads on GKE shared files over NFS: one more server to patch, size and back up.
    Constraint
    No service disruption for the tenants.
    Decision
    Replaced NFS with GCS Fuse, provisioned with Terraform and mounted through the Helm chart.
    Result
    No NFS server left to patch, size or back up for this workload.

    03

    Releases promoted by ArgoCD Image Updater

    Context
    Each new image needed a manual edit of the manifests before it reached production.
    Constraint
    Every change had to go through Git, so the state of each environment stays reviewable.
    Decision
    ArgoCD Image Updater detects new images and updates the target environment from Git, with no manual edit in the release path.
    Result
    New builds reach live environments without a manual step, and Git shows what runs where.

    04

    Automated cloud cost estimates

    Context
    Cloud cost estimates were slow to build by hand and risky to share with clients.
    Constraint
    Every figure must be traceable, and internal details must never reach the client file.
    Decision
    An AI-agent skill reads official list prices from the provider billing API and generates formula-based workbooks from a data model. Client and internal views are separate.
    Result
    Each estimate is recomputed, scanned for confidential terms and reviewed by an independent agent before it reaches the client.
